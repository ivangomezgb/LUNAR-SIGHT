# web

Frontend of Lunar Landing Site Navigator (Vite + React + TypeScript). See the [root README](../README.md).

- `npm run dev`: dev server with real data from `public/data/`
- `node scripts/make-dev-data.mjs` then `VITE_DATA_DIR=dev-data npm run dev`: synthetic data (never shipped)
- `npx vitest run`: metrics engine tests
