# Global Moon textures

- `lroc_color_poles_4k.jpg` — LROC WAC color mosaic with LOLA-filled poles, 4096 x 2048,
  equirectangular, centred on 0° longitude (converted to JPEG from `lroc_color_poles_4k.tif`).
- `ldem_3_8bit.jpg` — LOLA global elevation, 8-bit, 1024 x 512 (used as a bump map, relief only).

Source: CGI Moon Kit, NASA's Scientific Visualization Studio, https://svs.gsfc.nasa.gov/4720
Credit: NASA's Scientific Visualization Studio.

Context imagery for the orbital globe only; every number in the app comes from the LOLA/SPICE pipeline.
